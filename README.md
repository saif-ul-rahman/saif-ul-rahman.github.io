# AI Engineer Portfolio

A dependency-free Jekyll portfolio designed for GitHub Pages. It uses semantic HTML, responsive CSS, and Markdown posts.

## Personalize

Update `YOUR NAME`, `hello@example.com`, and the GitHub/LinkedIn URLs in `_layouts/default.html` and `index.html`. Project content lives in `index.html`; articles live in `_posts/` and follow Jekyll's `YYYY-MM-DD-title.md` naming convention.

## Deploy with GitHub Pages

Push this repository to GitHub, then open **Settings → Pages**, choose **Deploy from a branch**, and select the branch containing this site (typically `main`) and the repository root. GitHub Pages will build the included Jekyll site automatically.

For a project site hosted below a repository name, set `baseurl: "/repository-name"` in `_config.yml`.
